# opskit/flows — flow template library

- Follow the "Custom pieces & flow template rules" in `.claude/CLAUDE.md`. One folder per template: `flow.json`, `template.yaml` (manifest, `opskit/schema/template.schema.json`), `README.md`, `test/`, `CHECKLIST.md`. Rules: `CONVENTIONS.md`.
- No real IDs, keys, emails or sheet URLs in `flow.json` — placeholders only.
- A template is done only after importing and passing its sample run on a fresh CE stack.
